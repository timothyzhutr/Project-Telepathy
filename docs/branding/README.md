# Logo explorations

The [concept sheet](logo-concepts.svg) contains three original vector sketches. They are design explorations and are not bundled as app resources.

**Context link** is the preferred starting point: square text brackets suggest an input method, while two connected points express preceding text informing the next word. It works in one colour and does not depend on the current model's name.

**Text gesture** recalls 文 and makes the Chinese writing connection explicit. **Quiet echo** expresses telepathy more literally, but could be mistaken for a messaging app.

Before adopting a mark, refine optical weight at 16–22 px, prepare a macOS template image and a separate app-icon tile, and check for confusingly similar existing marks. These sketches have not undergone a trademark search.

Original artwork created for Project Telepathy; distributed under the repository's GPL-3.0 license.
